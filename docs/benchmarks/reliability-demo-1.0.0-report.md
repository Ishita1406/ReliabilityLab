## Limitations and sources of uncertainty

- **Synthetic and tiny.** Five fictional cases and 16 scenarios; results say nothing about real-world research tasks or real language models.
- **Repetitions are not independent samples.** The agents are deterministic and every fault fires with probability 1, so repetitions of a scenario give identical results. The effective sample size is the number of scenarios (16), not the number of runs; run-level intervals above treat runs as independent and are therefore too narrow.
- **Low statistical power.** With 16 paired scenarios a one-directional change needs at least 6 discordant scenarios to reach p < 0.05; smaller regressions are flagged by the zero-tolerance policy, not by significance.
- **Virtual time.** Latency is measured on the runner's manual clock (injected delays and back-off), not wall-clock performance.
- **Cost is trivially zero.** The deterministic agent makes no model calls; cost is a known zero, not an estimate for LLM agents.
- **Evaluator limits.** Text-matching criteria cannot tell an assertion from a quotation; no rubric/LLM judging and no human labels were used, so evaluator accuracy is unmeasured (see Milestone 8).
- **Expectations encode one view of correct behaviour.** E.g. the misleading-output scenario expects an answer (two sources remain consistent); the reference agent reports a conflict instead and fails it. That is a documented, intentional controlled failure.
